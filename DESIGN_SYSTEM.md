# Huilin Shen — Portfolio design notes

The current homepage is a project gallery. Case studies follow a consistent editorial layout, with clear type hierarchy, generous spacing, chapter navigation and project-specific visual accents. The Huawei Calendar case study uses a white background and blue accent; the other project pages retain their own palettes.

Use the live components and styles as the source for spacing, typography, responsive behaviour and navigation. Preserve each project's content order and visual identity when making layout changes.

The former 3D amusement-park concept is archived in `components/park/` and is not used by the current homepage.
